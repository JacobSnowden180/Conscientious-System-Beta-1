# Consciousness System Beta 1

A single-page marketing site for **Consciousness System**, a hands-free AI teammate for everyday life. It works across files, the web, and messages you approve, and it keeps routines like a printable day schedule.

The page is plain HTML, CSS, and JavaScript. There is no build step and no backend. The beta form only shows a confirmation in the browser. It does not send or store the email address.

## Open it

Open `index.html` in a browser.

Or serve the folder:

```bash
python3 -m http.server 43123
```

Then visit [http://127.0.0.1:43123](http://127.0.0.1:43123).

The intended typefaces (Fraunces and Outfit) load from Google Fonts when you are online. Offline, the page falls back to Palatino and a system sans serif.

## On the page

- Hero and a sample day sheet
- Six areas of life, then six feature cards
- Three steps for how it works
- Four everyday scenes
- A short privacy note
- A join-the-beta form with a client-side thank-you
